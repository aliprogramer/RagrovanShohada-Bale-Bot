## 📖 معرفی

**حلقه‌های رهروان شهدا** یک بات بله (Bale) است که به‌صورت **Supabase Edge Function** روی **Deno** اجرا می‌شود. این بات فرایند مربی‌گری را گیمیفای می‌کند: مربی‌ها مأموریت تعریف می‌کنند، متربی‌ها فعالیت خود را ارسال می‌کنند، مربی آن را بررسی می‌کند و پس از تأیید، امتیاز (XP) به حساب متربی اضافه می‌شود. با جمع شدن امتیاز، سطح و نشان‌ها باز می‌شوند و امتیازها قابل تبدیل به جایزه هستند.

> تمام تعامل کاربر با **کیبوردهای دکمه‌ای** انجام می‌شود و نیازی به تایپ دستور نیست.

---

## ✨ قابلیت‌ها

### 👑 مدیر (Admin)
- مدیریت کاربران: فهرست مربی‌ها، متربی‌ها و همه کاربران
- افزودن مربی با **لینک دعوت** و کد ۶ رقمی
- فعال/غیرفعال‌سازی کاربر، بازنشانی اتصال بله، تغییر مربیِ متربی
- نظارت و گزارش مأموریت‌ها
- تعریف جایزه (هزینه، موجودی، توضیح) و بررسی درخواست‌های دریافت جایزه
- داشبورد گزارش کلی (کاربران، مأموریت‌ها، مجموع امتیازها)

### 👨‍🏫 مربی (Coach)
- افزودن متربی با لینک دعوت اختصاصی
- ایجاد مأموریت (عنوان، توضیح، امتیاز) و آرشیو کردن آن
- واگذاری مأموریت به **یک متربی**، **چند متربی** یا **همه متربی‌های فعال**
- بررسی فعالیت‌های ارسالی و **تأیید/رد** با اعلان خودکار به متربی
- گزارش عملکرد شخصی

### 🎓 متربی (Trainee)
- مشاهده مأموریت‌های فعال و ارسال گزارش انجام کار
- پیگیری وضعیت فعالیت‌ها (در انتظار / تأیید / رد)
- کارت امتیاز، **۱۰ سطح** پیشرفت و مسیر رشد
- نشان‌های افتخار بر پایه امتیاز
- رتبه‌بندی ۱۰ نفر برتر
- درخواست جایزه با امتیاز (با بازگشت خودکار امتیاز در صورت رد)

## 🏗️ معماری

```
┌──────────────┐   Webhook (POST)   ┌─────────────────────────┐
│  Bale Bot    │ ─────────────────▶ │  Supabase Edge Function │
│  (tapi.bale) │ ◀───────────────── │        (Deno)           │
└──────────────┘    sendMessage     └───────────┬─────────────┘
                                                │ supabase-js
                                                ▼
                                    ┌─────────────────────────┐
                                    │   Supabase PostgreSQL   │
                                    └─────────────────────────┘
```

- **State machine:** وضعیت مکالمه هر کاربر در ستون‌های `bot_state` و `bot_temp_data` جدول `kanoon_users` ذخیره می‌شود، بنابراین تابع کاملاً stateless است.
- **ناوبری سراسری:** زدن هر دکمه منو، وضعیت جاری را لغو می‌کند و دکمه «🔙 بازگشت» در همه مراحل کار می‌کند.
- **کدهای مأموریت:** شناسه عددی به کد خوانا تبدیل می‌شود (مثلاً `M100`).

## 🗄️ ساختار دیتابیس

| جدول | کاربرد |
|------|--------|
| `kanoon_users` | کاربران، نقش، امتیاز، سطح، وضعیت فعال‌سازی، کد دعوت و state بات |
| `missions` | مأموریت‌ها (عنوان، توضیح، پاداش، سازنده، وضعیت فعال) |
| `mission_assignments` | واگذاری مأموریت به متربی‌ها (یکتا بر اساس `mission_id, trainee_id`) |
| `mission_submissions` | فعالیت‌های ارسالی و وضعیت بررسی (`pending / approved / rejected`) |
| `xp_transactions` | دفتر تراکنش‌های امتیاز |
| `badges` / `user_badges` | نشان‌ها و نشان‌های کسب‌شده (یکتا بر اساس `name` و `user_id, badge_id`) |
| `rewards` | جوایز (هزینه، موجودی، وضعیت) |
| `reward_redemptions` | درخواست‌های دریافت جایزه |

> ⚠️ کلیدهای یکتا (`onConflict`) که در کد استفاده شده‌اند باید به‌صورت **UNIQUE constraint** در دیتابیس تعریف شوند.

## 🚀 راه‌اندازی

### پیش‌نیازها
- حساب [Supabase](https://supabase.com) و نصب [Supabase CLI](https://supabase.com/docs/guides/cli)
- یک بات در بله (ساخته‌شده با `@botfather`) و دریافت توکن

### ۱. کلون پروژه
```bash
git clone https://github.com/<username>/<repo>.git
cd <repo>
```

### ۲. تنظیم Secrets
```bash
supabase secrets set BALE_BOT_TOKEN=<توکن بات بله>
supabase secrets set SB_SERVICE_ROLE_KEY=<service role key پروژه>
```

| متغیر | توضیح |
|-------|-------|
| `BALE_BOT_TOKEN` | توکن بات بله |
| `SB_SERVICE_ROLE_KEY` | کلید `service_role` سوپابیس |
| `SUPABASE_URL` | به‌صورت خودکار توسط Supabase تنظیم می‌شود |

### ۳. دیپلوی
```bash
supabase functions deploy <function-name> --no-verify-jwt
```

> ⚠️ **مهم:** گزینه‌ی **Verify JWT with legacy secret** باید **خاموش** باشد؛ چون بله هنگام فراخوانی وب‌هوک هدر Authorization سوپابیس ارسال نمی‌کند.

### ۴. تنظیم وب‌هوک بله
```bash
curl "https://tapi.bale.ai/bot<BALE_BOT_TOKEN>/setWebhook" \
  -d "url=https://<project-ref>.supabase.co/functions/v1/<function-name>"
```

### ۵. ساخت اولین مدیر
یک رکورد با `role = 'admin'` در جدول `kanoon_users` ایجاد کنید و `bale_chat_id` را برابر شناسه چت خودتان قرار دهید، سپس در بات `/start` بزنید.

## 🔐 نکات امنیتی

- کلید `service_role` را **هرگز** در کد یا ریپازیتوری قرار ندهید؛ فقط از طریق Secrets.
- با خاموش بودن JWT، آدرس تابع عمومی است؛ برای امنیت بیشتر پیشنهاد می‌شود یک **secret token** در آدرس وب‌هوک بگذارید و در تابع بررسی کنید.
- دسترسی هر نقش در سمت سرور بررسی می‌شود (مثلاً مربی فقط متربی‌ها و مأموریت‌های خودش را می‌بیند).
